## 2. System Requirements

### 2.1 Server Requirements

**Backend Server:**
- PHP 8.4 or higher
- Composer 2.x
- MySQL 8.0 or higher
- Redis 6.x or higher
- Nginx 1.24+ or Apache 2.4+
- SSL Certificate (Let's Encrypt)
- Minimum 2GB RAM (4GB recommended)
- Minimum 2 CPU cores (4 cores recommended)
- 20GB SSD storage minimum

**Frontend Build Server:**
- Node.js 20.x LTS or higher
- NPM 10.x or higher
- Git 2.x

### 2.2 Development Environment

**Required Software:**
- Docker Desktop 24.x
- Docker Compose 2.x
- Visual Studio Code or PHPStorm
- Git
- Postman or Insomnia (API testing)
